# Замечания к документации и исправления

## Выявленные противоречия (Риски для пользователя)
1. **Лимит вложений:** В старом руководстве (1.4.2) указано 5 файлов. В спецификации (1.5.0) — не более 3.
   * *Риск:* Пользователь приложит 4-й файл, получит ошибку и потеряет время.
2. **Совет при тайм-ауте:** В старом руководстве указано «Нажимайте Отправить до появления номера».
   * *Риск:* Многократная отправка создаст дубли заявок, так как операция могла уже сохраниться на сервере.
3. **Версия руководства:** Руководство в пакете имеет версию 1.4.2, а релиз — 1.5.0-rc1.

## Исправленный фрагмент руководства (для версии 1.5.0)

**Раздел «Вложения»:**
> В поле «Вложения» приложите файлы PDF или PNG — не больше 3 штук, каждый не больше 5 000 000 байт. Пустой файл не принимается.

**Раздел «Ошибка сети (тайм-аут)»:**
> Если появилось сообщение «Не удалось получить ответ. Проверьте список заявок перед повтором», **НЕ НАЖИМАЙТЕ «Отправить» сразу**. Перейдите в список заявок (фильтр «Мои»). Если запись уже есть — повторять не нужно. Если записи нет — обратитесь в поддержку, сохранив введенный текст.
