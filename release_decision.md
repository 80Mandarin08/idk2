# Решение о готовности выпуска

**Статус:** **ОСТАНОВИТЬ ВЫПУСК** (Release Blocked).

**Обоснование:**
1. Критический сценарий `R_RESTORE` имеет статус **blocked**. Проверка восстановления не проведена, подтверждения RTO/RPO нет. Выпуск без проверенного восстановления недопустим.
2. Требование `R_PERFORMANCE` имеет статус **not_run**. Мы не знаем, выдержит ли система нагрузку.
3. Документация в пакете устарела и содержит опасные советы (многократная отправка).
*Пороги качества не могут быть снижены ради принятия непроверенного кандидата.*

## Условия для пересмотра решения
Решение может быть пересмотрено только после выполнения следующих действий:
1. **Проверка восстановления:** Организовать целевой ресурс и успешно провести T04. Владелец: `teacher_release`. Доказательство: отчет о восстановлении с фиксацией RTO и RPO.
2. **Нагрузочное тестирование:** Провести T05 по заданной методике. Владелец: `student_tester`. Доказательство: лог теста с рассчитанным p95 и долей успеха.
3. **Обновление документации:** Заменить старое руководство (1.4.2) на исправленное.
