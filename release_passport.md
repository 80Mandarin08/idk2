# Паспорт выпуска 1.5.0-rc1

**Кейс:** DOC-17

**Цель:** Подготовка к внедрению обновления, расширяющего схему данных.

**Состав:** Пакет `app-1.5.0-rc1.zip`. Исходный код: `DEMO-COMMIT-015-NOT-A-REAL-GIT-ID` (учебный маркер, не Git-хеш).

**Среда:** Linux x64, Python 3.11/3.12, PostgreSQL 15/16. Свободное место: минимум 2048 МиБ.

**Миграция:** M015 (расширяющая, переход S1 -> S2).

**Статус готовности:** **НЕ ГОТОВ**. Выпуск заблокирован из-за отсутствия подтверждения восстановления (R_RESTORE) и непроведенного теста производительности (R_PERFORMANCE).

## Параметры (конфигурация)
| Параметр | Значение / Назначение |
|---|---|
| APP_PORT | 8081 (порт приложения) |
| DB_HOST | lab-db-01 (хост базы данных) |
| DB_NAME | service_lab (имя базы) |
| ATTACHMENTS_DIR | /srv/service_lab/attachments (путь к файлам) |
| max_attachments | 3 (согласно SPEC-1.0) |
*Секреты в паспорт не входят, передаются отдельным механизмом.*

## Ограничения и неизвестные
1. Совместимость со старой версией 1.4.2 после включения функции `category_required` не проверена.
2. Резервная копия `B-1755` есть, но последнее успешное испытание восстановления отсутствует в пакете (`not_available_in_packet`).
3. Контроль целостности пакета не подтвержден (нет вычисленного хеша, только имя файла).
